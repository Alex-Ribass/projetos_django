# 🚀 Projetos Django & Django REST Framework

Este repositório reúne aplicações web e APIs RESTful desenvolvidas com **Django** e **Django REST Framework (DRF)**, focando em boas práticas de arquitetura REST, modelagem de dados e regras de negócio no desenvolvimento backend com Python.

---

## 🎯 Objetivos do Repositório

- **Desenvolvimento Backend:** Construção de ecossistemas robustos para web e APIs RESTful.
- **Serialização e Validação:** Tratamento e higienização de dados de entrada/saída com regras de validação personalizadas em nível de campo e de objeto.
- **Arquitetura de Views:** Exploração prática de diferentes níveis de abstração, desde o controle de baixo nível (`APIView`) até estruturas avançadas e reutilizáveis (`GenericAPIView`, `Mixins` e `ModelViewSet`).
- **Padrões HTTP:** Mapeamento explícito de rotas, manipulação rigorosa de verbos HTTP (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`) e gerenciamento adequado de códigos de status (`200`, `201`, `204`, `400`, `404`).
- **Banco de Dados & ORM:** Modelagem relacional, execução de migrações e consultas otimizadas utilizando o ORM do Django.

---

## 🛠️ Tecnologias e Ferramentas

- **Python 3.13+**
- **Django**
- **Django REST Framework (DRF)**
- **SQLite**
- **Git & GitHub**
